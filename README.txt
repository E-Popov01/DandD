This will be a little text based game, strongly inspired by Dungeons and Dragons.
Therefore this file will mainly be for the definition of the classes, attacks, enemies and such, so it is clear how the game was intended to be played.
I myself have only once played D&D. If you finde faults not only in my code, but the game itself, feel free to correct them. This is supposed to be a bit of exercise and fun for me. Not to properly develope a D&D game. I am also quite certain, that such a thing already exists.

Stats:

Strength
    Influences damage from physical attacks and how a character can use brute force to influence NPCs
    Also how much a character can carry
Dexterity
    Agility, Reflexes, Balance
Constitution
    Measures a character's health, stamina and resistance to physical stress
Intelligence
    Mainly influences magical forces and ability to analyse
Wisdom
    Willpower common sense, perception and intuition
Charisma
    persuasiveness, gravitas, ability to lead, physical attractiveness
